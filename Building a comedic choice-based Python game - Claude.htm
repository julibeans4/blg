  1. 1

  2. 2
    Build the web versionRun `pygbag main.py`. It starts a local server (usually http://localhost:8000) so you can immediately test the browser build, and it generates a `build/web/` folder containing `index.html`, the compiled game, and supporting files.
  3. 3
    Test it in a browserOpen the localhost URL pygbag prints in the terminal. Click through the game exactly like you would on the real site. First load takes a few seconds while the WASM runtime downloads — that's normal, not a bug.
  4. 4
    Copy build/web into your site's project folderCreate a folder in your website's project (e.g. `games/nap-time-nation/`) and copy everything from `build/web/` into it. This folder is now a self-contained, static, drop-in unit — it doesn't need Python running anywhere once it's built.
  5. 5
    Embed it in a pageIn whatever HTML page you want the game on, add an iframe pointing at the copied index.html: `<iframe src="/games/nap-time-nation/index.html" width="960" height="540" style="border:none;" allowfullscreen></iframe>`. Adjust the path to match your site's folder structure.
  6. 6
    Deploy your site as usualSince it's just static files (HTML/JS/WASM), it deploys the same way as the rest of your site — push to GitHub Pages, drag-and-drop to Netlify, upload via FTP, whatever you already do.
